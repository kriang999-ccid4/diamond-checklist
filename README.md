# Diamond Checklist — คู่มือติดตั้ง

แอปเช็กลิสต์ประจำวัน ติ๊กได้ทั้งจากมือถือและคอม ข้อมูลไปลง Google Sheets 3 ไฟล์ในโฟลเดอร์ **Diamond Amway Project** บน Google Drive โดยตรง

| ในแอป | ไปลงที่ |
| --- | --- |
| เช็กลิสต์ + ตัวเลขธุรกิจ | ไฟล์ "แผน 1 ปี 1 ล้าน" ชีต **บันทึกเช็กลิสต์** (เก็บทุกวัน) และชีต **Checklist รายวัน** (แถวตามวันที่) |
| ผู้มุ่งหวัง | ไฟล์ "แบบลิสรายชื่อผู้มุ่งหวัง" แถวว่างแถวแรก |
| นัดหมาย | ไฟล์ "ตารางงานเกรียง2026" ชีตเดือนนั้น ช่องวันที่และเวลา (ต่อท้าย ไม่ลบข้อความเดิม) |

ขึ้นเดือนใหม่ สคริปต์จะเก็บชีต Checklist รายวันของเดือนเก่าไว้เป็นสำเนา แล้วล้างเทมเพลตให้อัตโนมัติ ขึ้นปี 2570 จะสร้างชีตเดือนใหม่ในตารางงาน เช่น "ม.ค 70" ให้เอง

ทั้งหมดมี 2 ส่วน:

- `apps-script/Code.gs` = หลังบ้าน อยู่ใน Google Sheet ของคุณ
- `docs/` = หน้าแอป วางบน GitHub Pages จะไม่มีแถบข้อความของ Google ด้านบน

---

## ขั้นที่ 1: ติดตั้งหลังบ้าน (ประมาณ 5 นาที)

1. เปิดไฟล์ **แผน 1 ปี 1 ล้าน (Sep 2026-Aug 2027)** ใน Google Drive
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs` ลงไป กดบันทึก (ไอคอนแผ่นดิสก์)
4. แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์ ให้กด อนุญาต (ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced → Go to … (unsafe) เพราะเป็นสคริปต์ที่คุณเป็นเจ้าของเอง)
   - ดูที่ **บันทึกการดำเนินการ (Execution log)** จะมีบรรทัด `รหัสลับของแอป …` ให้คัดลอกรหัสเก็บไว้
5. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
   - กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`)

> ตั้งเป็น "ทุกคน" เพื่อให้หน้าแอปบน GitHub เรียกได้ แต่ทุกคำสั่งต้องมีรหัสลับที่ตรงกัน ไม่มีรหัส = อ่านหรือเขียนอะไรไม่ได้

**แก้โค้ดภายหลัง:** Deploy → Manage deployments → ไอคอนดินสอ → Version: New version → Deploy (URL เดิมยังใช้ได้)

## ขั้นที่ 2: วางหน้าแอปบน GitHub Pages (ประมาณ 5 นาที)

1. เข้า github.com → ปุ่ม **New repository** ตั้งชื่อ เช่น `diamond-checklist` เลือก **Public** → Create
2. ในหน้า repo กด **uploading an existing file** แล้วลาก **โฟลเดอร์ `docs` ทั้งโฟลเดอร์** (หรือทั้งโฟลเดอร์ `diamond-checklist`) ลงไป → Commit changes
3. ไปที่ **Settings → Pages** ช่อง Source เลือก **Deploy from a branch** → Branch: `main` โฟลเดอร์ `/docs` → Save
4. รอ 1–2 นาที จะได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/diamond-checklist/`

> repo เป็น Public ได้อย่างปลอดภัย เพราะในโค้ดไม่มีข้อมูลลูกค้า ไม่มีลิงก์เว็บแอป และไม่มีรหัสลับ ทั้งสองอย่างเก็บไว้ในเครื่องของคุณเท่านั้น

## ขั้นที่ 3: เชื่อมต่อในแต่ละเครื่อง (ทำครั้งเดียวต่อเครื่อง)

1. เปิดลิงก์ GitHub Pages ระบบจะพาไปหน้า **ตั้งค่า**
2. วาง URL เว็บแอป (`/exec`) และรหัสลับ → **บันทึกและทดสอบ**
3. **มือถือ:** เปิดใน Chrome (Android) เมนู ⋮ → Add to Home screen / Safari (iPhone) ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอน Diamond เปิดเต็มจอเหมือนแอป

## ความปลอดภัย

- รายชื่อผู้มุ่งหวังเป็นข้อมูลส่วนบุคคลของคนอื่น (PDPA) ข้อมูลอยู่ใน Google Sheet ของคุณเท่านั้น ไม่ได้ผ่าน GitHub
- มือถือหายหรือคิดว่ารหัสรั่ว: เปิด Apps Script แล้วรันฟังก์ชัน **resetKey** จะได้รหัสใหม่ รหัสเดิมใช้ไม่ได้ทันที จากนั้นใส่รหัสใหม่ในเครื่องที่ยังใช้อยู่
- ปุ่ม "ลบการเชื่อมต่อจากเครื่องนี้" ในหน้าตั้งค่า ใช้ก่อนคืนหรือขายเครื่อง

## ปรับรายการงาน

รายการงานแต่ละวันอยู่ในฟังก์ชัน `tasksFor` ใน `docs/index.html` แก้ข้อความหรือเวลาได้เลย แต่ให้คงคีย์เดิมไว้ (`link`, `body`, `coffee`, `meditate`, `clinic`, `plan`, `cyber`, `follow`, `online`, `review`) เพราะเป็นชื่อคอลัมน์ในชีตบันทึกเช็กลิสต์
